# 撮影リスト（page-flow / page-company / page-about）

最終更新: 2026-09-17

フリー素材から自前の写真に差し替えるための撮影リストです。撮影・アップロード後、管理画面（ACF）または`assets/img/`配下の該当ファイルに差し替えてください。

## 共通の撮り方の方針

- **同じ机・同じ照明・同じ角度**で撮ると、バラバラの素材写真よりずっと「らしさ」が出ます。奈良の自宅兼事務所の作業スペースをそのまま使うのがおすすめです。
- 高価な機材は不要。**スマホの俯瞰撮影（真上から）**か、**PC画面のスクリーンショット**で十分です。
- 実際の案件データが映り込む場合は、社名・金額・個人名などをモザイク/ぼかし処理してください。
- 人物写真（手元・後ろ姿含む）は、後で他のページでも使い回せるよう複数カットを撮っておくと後々楽です。
